Скрипты для версии приложения с использованием Express.js и MongoDB:
1. Компиляция TS-файлов из папки "src" в папку "dist" в режиме наблюдения (-w): pnpm watch
2. Запуск приложения при помощи nodemon, следя за изменениями в скомпилированном коде в папке "dist": pnpm dev
3. Запуск тестов при помощи Jest: pnpm jest
4. Форматирование кода при помощи Prettier: pnpm format
5. Запуск проверки кода при помощи ESLint и автоматического исправления части ошибок: pnpm lint
6. Компиляция TS-файлов из папки "src" в папку "dist". Нужно для деплоя на vercel.com: pnpm build
7. Запуск приложения, нужно для деплоя на vercel.com: pnpm start

Скрипты для версии приложения с использованием NestJS и MongoDB/PostgreSQL:
1. Создание модуля: nest g module modules/module_name.
2. Создание контроллера без файла для тестов: nest g controller modules/module_name --no-spec.
3. Создание сервиса без файла для тестов: nest g service modules/module_name --no-spec.
4. Получить все команды, генерирующие шаблонные сущности: nest g --help.
5. Быстрое развертывание приложения в облаке (требует заранее подготовленных инфраструктуры и конфигов): nest deploy
6. Компиляция TS-файлов из папки "src" в папку "dist" с использованием файла "tsconfig.build.json": nest build
7. Форматирование кода при помощи Prettier: prettier --write "src/**/*.ts" "__tests__/**/*.ts"
8. Запуск проверки кода при помощи ESLint и автоматического исправления части ошибок: eslint "{src,apps,libs,__tests__}/**/*.ts" --fix
9. Запуск проверки кода при помощи Oxlint: oxlint src/ __test__/
10. Запуск приложения: nest start
11. Запуск приложения в режиме наблюдения: cross-env NODE_ENV=development nest start --watch
12. Запуск приложения в режиме наблюдения c открытием порта для подключения отладчика: cross-env NODE_ENV=development nest start --debug --watch
13. Запуск приложения из папки "dist": node dist/main
14. Запуск тестов при помощи Jest: jest
15. Запуск тестов при помощи Jest в режиме наблюдения: jest --watch
16. Запуск тестов при помощи Jest c генерацией отчета о покрытии кода: jest --coverage
17. Запуск пошаговой отладки тестов в IDE: node --inspect-brk -r tsconfig-paths/register -r ts-node/register node_modules/.bin/jest --runInBand
18. Генерация миграции: cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:generate -d ./src/migrations/config/typeorm.config.ts
19. Применение всех миграций, которые еще не были приняты, в порядке их отметок времени: cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:run -d ./src/migrations/config/typeorm.config.ts
20. Откат последней примененной миграции: cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:revert -d ./src/migrations/config/typeorm.config.ts
21. Создание пустого файла миграции: cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:create ./src/migrations/
